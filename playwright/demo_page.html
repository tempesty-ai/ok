    자주 묻는 질문

    Playwright는 Microsoft에서 만든 최신 테스트 프레임워크로, 브라우저를 직접 제어하고 네트워크 인터셉트, 자동 대기 등 현대적인 기능을 기본 제공합니다. Selenium은 오래된 생태계를 가지며 다양한 언어를 지원합니다.
    Python 기초 문법 → Selenium/Playwright 기본 동작 → CSS/XPath 셀렉터 → 테스트 설계(TC 작성) 순서로 학습하는 것을 권장합니다. CI/CD 연동은 이후 단계입니다.
    페이지의 요소와 동작을 클래스로 분리하는 디자인 패턴입니다. UI가 바뀌어도 해당 페이지 클래스만 수정하면 되므로 유지보수성이 크게 향상됩니다.
    Headless 모드란 브라우저 UI 없이 백그라운드에서 실행하는 방식입니다. CI 서버처럼 화면이 없는 환경에서 유용하며 실행 속도가 빠릅니다.
